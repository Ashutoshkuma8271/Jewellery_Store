# A_S JEWELLERY ATELIER

A premier luxury retail web application and fine jewelry atelier experience handcrafted with React, TypeScript, Tailwind CSS, and Vite.

## ✨ Features

- **Luxury Brand Experience**: Handcrafted gold, certified diamonds, and heirloom jewelry collections.
- **Interactive Jewelry 360° Studio**: 360-degree rotation viewer and high-definition zoom.
- **Omnichannel Checkout**: Integrated Razorpay payment workflow and simulated express order placement.
- **Concierge & Member Portals**: Role-based VIP membership and atelier administration suite.
- **Responsive & Dark Mode Ready**: Elegant modern UI with tailored typography and micro-animations.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Run Locally
```bash
npm run dev
```
- Frontend will run on: `http://localhost:5174`
- Backend API will run on: `http://localhost:4001`

---

## 🌐 Deploy to Vercel

This repository includes a pre-configured `vercel.json` for single-click deployment:

1. Push this repository to GitHub.
2. Import the repository into [Vercel](https://vercel.com).
3. Set Framework Preset to **Vite**.
4. Build Command: `npm run build` or `vite build`
5. Output Directory: `dist`
6. Click **Deploy**.
